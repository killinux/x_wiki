# 骨骼 (ボーン / bones)

MMD 模型靠骨骼驱动变形。要复用现成 VMD 动作,骨骼**命名与结构必须遵循 MMD 半标准**,否则动作对不上。

## 标准骨骼命名(日文为准)
MMD 动作按**日文骨骼名**匹配,常见核心骨:

| 日文 | 中文 | 说明 |
|---|---|---|
| センター | 中心 | 全身根控制 |
| 上半身 / 上半身2 | 上半身 | 躯干 |
| 下半身 | 下半身 | 髋部 |
| 首 / 頭 | 脖子 / 头 | |
| 左/右 肩・腕・ひじ・手首 | 肩/臂/肘/手腕 | 左=左, 右=右 |
| 左/右 足・ひざ・足首 | 腿/膝/脚踝 | |
| 足ＩＫ / つま先ＩＫ | 脚 IK / 脚尖 IK | 见下 IK |

> 注意:全角字符(ＩＫ)等细节会影响匹配,以官方标准骨架为准。建议从标准模型或 [[cats-blender-plugin]] / 半标准骨架模板对照重命名。

## IK 骨骼
MMD 用 **IK(逆运动学)** 控制脚部贴地。`足ＩＫ`、`つま先ＩＫ` 是动作数据直接驱动的目标。Blender 的 IK 与 MMD 的 IK 求解方式不同,导出由 [[mmd_tools]] 转换。

## 附加变形(付与)
MMD 骨骼支持「付与親(回転付与/移動付与)」——一根骨按比例跟随另一根,常用于物理辅助、半自动表情骨。

## 在 Blender 中
- 用 Armature + Bone,命名对齐上表。
- 权重绑定见 [[权重-weights]]。
- 导出时 [[mmd_tools]] 负责把 Blender 骨骼转成 PMX 骨骼(含 IK / 付与信息,需在插件的 MMD Bone Tools 里设置)。

> 待补充:完整半标准 / 准标准骨架清单与各骨的父子关系——ingest 标准模型骨架后补全。
