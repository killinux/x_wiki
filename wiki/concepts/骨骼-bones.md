# 骨骼 (ボーン / bones)

MMD 模型靠骨骼驱动变形。要复用现成 VMD 动作,骨骼**命名与结构必须遵循 MMD 半标准**,否则动作对不上(VMD 按日文名匹配,见 [[vmd-动作格式]])。

## 标准骨骼命名(日文为准)
MMD 动作按**日文骨骼名**匹配,常见核心骨:

| 日文 | 中文 | 说明 |
|---|---|---|
| センター | 中心 | 全身根控制 |
| 上半身 / 上半身2 | 上半身 | 躯干 |
| 下半身 | 下半身 | 髋部 |
| 首 / 頭 | 脖子 / 头 | |
| 左/右 肩・腕・ひじ・手首 | 肩/臂/肘/手腕 | 左=左, 右=右 |
| 左/右 足・ひざ・足首 | 腿/膝/脚踝 | |
| 足ＩＫ / つま先ＩＫ | 脚 IK / 脚尖 IK | 见下 IK |

> ⚠️ **全角/半角**:核心骨常用全角字符(`ＩＫ`、`親指０`),VMD 精确匹配,全角半角不可混(实测见 [[标准骨架范本-reika]])。建议从标准模型或 [[cats-blender-plugin]] / 半标准骨架模板对照重命名。

## IK 骨骼
MMD 用 **IK(逆运动学)** 控制脚部贴地。`足ＩＫ`、`つま先ＩＫ` 是动作数据直接驱动的目标。Blender 的 IK 与 MMD 的 IK 求解方式不同,导出由 [[mmd_tools]] 转换。

- 实测标准 IK 链(范本 [[标准骨架范本-reika]]):`足ＩＫ` target=足首,链=[ひざ, 足](链长 2);`つま先ＩＫ` target=つま先,链=[足首](链长 1)。
- PMX 里 IK 由骨骼 flag 位 `0x0020` 标记,详见 [[pmx-format]]。

## 附加变形(付与)
MMD 骨骼支持「付与親(回転付与/移動付与)」——一根骨按比例跟随另一根,常用于物理辅助、半自动表情骨。准标准骨里的扭转骨(腕捩/手捩)和 D 系足骨(足D/ひざD/足首D)都靠付与工作。

- 实测付与系数(范本):肩C ← 肩P −1.0;腕捩1/2/3 ← 腕捩 0.25/0.5/0.75;足D/ひざD/足首D ← 足/ひざ/足首 1.0。详见 [[准标准骨骼-semi-standard-bones]]。
- PMX 里付与由 flag 位 `0x0100`(回転)/`0x0200`(移動)标记,见 [[pmx-format]]。

## 标准骨 vs 准标准骨
上表是**标准骨**(MMD 默认人型自带)。但很多 VMD 动作还会用到一组社区约定的**准标准骨**(腕捩/手捩/親指0/グルーブ/上半身2/足IK親/足先EX 等)。要让模型「吃得下」主流动作,通常两层都要补。完整清单与补法见 [[准标准骨骼-semi-standard-bones]]。

## 在 Blender 中
- 用 Armature + Bone,命名对齐上表。
- 注意骨骼 **roll(滚转轴)**:导入的外部模型 roll 常乱,会导致旋转扭曲,见 [[坐标系-朝向-pose]]。
- 权重绑定见 [[权重-weights]]。
- 导出时 [[mmd_tools]] 负责把 Blender 骨骼转成 PMX 骨骼(含 IK / 付与信息,需在插件的 MMD Bone Tools 里设置);完整建 IK/付与/显示枠流程见 [[blender-mmd-绑定改造]]。
