# 物理:刚体与关节 (剛体 / ジョイント)

MMD 用 **Bullet 物理**驱动头发、裙摆、饰品等的甩动。两大要素:

## 刚体 (剛体 / Rigid Body)
绑在骨骼上的物理碰撞体。关键属性:
- **类型**:
  - `骨骼追随(Bone)` — 跟着骨骼走,不受物理(用于碰撞器,如身体)。
  - `物理(Physics)` — 受重力/碰撞驱动(用于头发、裙子末端骨)。
  - `物理+骨骼对齐` — 物理但被拉回骨骼位置。
- **形状**:球 / 盒 / 胶囊。
- **分组与非碰撞组(group / no-collision mask)**:控制哪些刚体互相碰撞——**裙摆穿模/头发穿身体的核心调参点**。
- 质量、移动衰减、旋转衰减、回弹、摩擦。

## 关节 (ジョイント / Joint)
连接两个刚体,约束相对运动(对应 Bullet 的 6DOF Spring 约束):
- 位置/旋转的上下限
- 弹簧刚度
> 头发/裙子通常是「骨骼链 → 每节一个物理刚体 → 相邻刚体用关节相连」。

## 典型调参思路
- 穿模:调**非碰撞组**或加碰撞刚体(身体/腿做胶囊碰撞器)。
- 太软/太硬:调关节角度限制 + 弹簧刚度 + 刚体衰减。
- 抖动爆炸:质量差距过大、关节限制不合理、刚体重叠。

## 在 Blender 中
- [[mmd_tools]] 提供 Rigid Body / Joint 工具,可在 Blender 内创建并导出为 PMX 物理。
- Blender 自带的刚体系统**不直接等价**于 MMD 物理;以 mmd_tools 的 MMD 物理面板为准。
- 也常见做法:Blender 里只建模+绑骨,物理在 [[pmxeditor]] 里精修。

## 从零给 XPS 模型加物理(分步)

XPS 模型无物理,典型从零搭建(以一条头发/裙摆为例):

1. **建骨链**:沿头发/裙摆做一串骨(每段一根),末端骨刷 BDEF1 权重(见 [[权重-weights]])。
2. **身体做碰撞器**:给 上半身/下半身/頭/腕/足 等加**静(骨追従)刚体**(胶囊/箱),只碰撞不受力。
3. **飘动段做动刚体**:每节骨配一个**动(物理)刚体**。
4. **串关节**:相邻动刚体之间加一个关节;链根的动刚体与身体静刚体之间也加一个关节(把链「挂」在身上)。
5. **分组/非碰撞**:同一条链设同组且组内互不碰撞;与身体碰撞器设为会碰撞——这是防穿模的核心。
6. **测试**:mmd_tools 内播放物理或导出后在 MMD 里甩动观察。

## 参数经验值(实测自范本 [[标准骨架范本-reika]])

下列为一具完整模型的真实取值,可作起点:

| 参数 | 静(碰撞器) | 动(飘动) | 说明 |
|---|---|---|---|
| 质量 mass | 1.0 | **1.0** | 同链内质量保持一致,差距大会抖动 |
| 移动衰减 linear | 0.5 | **0.9** | 越大越「黏」、越快静止 |
| 旋转衰减 angular | 0.5 | **0.9** | 同上 |
| 回弹 restitution | 0.0 | **0.0** | 头发/布料不需要弹 |
| 摩擦 friction | 0.5 | **0.0** | 飘动件摩擦设 0 |

**关节(joint)实测**:头发/耳饰链的旋转限制约 **rotX ∈ [−10°, +10°]**,整体各链在 **±10° ~ ±30°** 之间;弹簧刚度多为 0(纯角度限制,不加回弹弹簧)。

> 该模型身体碰撞器(上半身=箱,下半身/首/腕=胶囊)用 mass 1 / 衰减 0.5 / 回弹 0 / 摩擦 0.5;飘动刚体把移动/旋转衰减拉到 **0.9**、摩擦与回弹都归 **0**。规模:48 刚体(胶囊40/箱6/球2,静20/动28)、29 关节。
>
> 注:数值随模型尺寸/风格变化,这只是一组**实测可用范本值**,不是唯一正解。
