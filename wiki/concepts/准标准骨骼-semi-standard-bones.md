# 准标准骨骼 (準標準ボーン / semi-standard bones)

MMD 的骨骼分两层:

- **标准骨骼(標準ボーン)** — MMD 默认人型「初音ミク」就有的骨骼,见 [[骨骼-bones]]。这是 VMD 动作匹配的最低要求。
- **准标准骨骼(準標準ボーン)** — 不在最初标准里,但社区广泛约定、**大量 VMD 动作会用到**的一组扩展骨骼。很多动作(尤其手部、扭转、足部细节)依赖它们才能正确表现。(来源: vpvpwiki 394, mmd.fandom 準標準ボーン)

> 实务结论:要让一个模型「吃得下」主流动作,**只补标准骨骼往往不够,准标准骨骼也要尽量补齐**。从 [[xps-format|XPS]] / VRoid 等外部来源转过来的模型,通常两层都缺。

## 怎么补 —— 准标准ボーン追加プラグイン

PMXEditor 有一个社区插件 **「準標準ボーン追加プラグイン」**(半自动添加准标准骨),是补这层骨骼的标准做法。它能在已有标准骨架上批量插入下列骨骼并自动设好父子/付与关系。(来源: vpvpwiki 394;niconico sm17648979 Ver2.0)

> 见 [[pmxeditor]]。也可在 Blender 端用 [[cats-blender-plugin]] / mmd_tools 处理一部分,但准标准骨的完整补全通常在 PMXEditor 里做最稳。

## 准标准骨骼清单

按身体部位列出(日文为准,VMD 按日文名匹配):

### 根/重心
| 日文 | 中/英 | 作用 |
|---|---|---|
| 全ての親 | 全部之父 / master・root | 全局根骨,平移/旋转整个模型 |
| グルーブ | groove | 位于 センター 与腰之间,做上下等微调 |
| 腰 | waist | 位于下半身与 センター 之间,统一控制腰部朝向 |

### 躯干
| 日文 | 中/英 | 作用 |
|---|---|---|
| 上半身2 | upper body 2 | 上半身与首之间,胸/上背更自然弯曲 |

### 肩・臂(扭转系)
| 日文 | 中/英 | 作用 |
|---|---|---|
| 肩P / 肩C | shoulder P / shoulder cancel | 肩的「付与」控制对,抵消肩随臂联动 |
| 腕捩 | 臂捻 / arm twist | 上臂内的扭转骨,改善大臂扭转时的形变 |
| 手捩 | 手捻 / wrist(forearm) twist | 前臂内的扭转骨,改善靠近手腕的扭转 |

### 手指
| 日文 | 中/英 | 作用 |
|---|---|---|
| 親指0 | 拇指0 / thumb 0 | 拇指根部追加骨,拇指开合更自然 |
| ダミー | dummy | 手持物专用(挂武器/道具),非形变骨 |

### 足(IK / D 系 / EX)
| 日文 | 中/英 | 作用 |
|---|---|---|
| 足IK親 | 足IK之父 / leg IK parent | 足IK的父骨,方便整脚定位 |
| 足D / ひざD / 足首D | 足D / 膝D / 踝D | 足部的「D(形变)」系骨骼,与可见足骨用付与联动,专管蒙皮形变,使膝/踝形变更干净 |
| 足先EX | 趾尖EX / toe EX | 脚趾追加骨,脚尖关节表现 |

### 其他
| 日文 | 中/英 | 作用 |
|---|---|---|
| 操作中心 | 操作中心 / control center | 编辑/操作辅助骨,非形变骨;部分插件版本可一并添加 |

> **D 系骨骼的意义**:把「控制」与「形变」分离 —— 可见的 足/ひざ/足首 负责接收动作,足D/ひざD/足首D 通过付与跟随,专门驱动蒙皮,从而避免膝盖等处的扭曲。(来源: blneder-vrc 2022-05-30)

## 付与系数实测值(来自范本 [[标准骨架范本-reika]])

下列系数由解析一具完整 PMX 得到,可直接套用:

| 子骨 | 付与源 | 类型 | 系数 |
|---|---|---|---|
| 肩C | 肩P | 回転 | **-1.0**(抵消) |
| 腕捩1 / 腕捩2 / 腕捩3 | 腕捩 | 回転 | **0.25 / 0.5 / 0.75** |
| 手捩1 / 手捩2 / 手捩3 | 手捩 | 回転 | **0.25 / 0.5 / 0.75** |
| 足D / ひざD / 足首D | 足 / ひざ / 足首 | 回転 | **1.0**(完全跟随) |
| 目 | 両目 | 回転 | 1.0 |
| 腰キャンセル左/右 | 腰 | 回転 | -1.0 |

> 即:腕捩/手捩 各带 3 个分散子骨(1/2/3)做「捩り分散」;肩C 用 -1.0 抵消肩P。详见范本页。

> 注:本表为常见配置;不同插件版本/模型实际补的子集可能不同(如是否含 肩C/ダミー/操作中心)。范本 [[标准骨架范本-reika]] 这具都齐。全角/半角细节(如 `親指０` vs `親指0`)务必和目标动作一致。
