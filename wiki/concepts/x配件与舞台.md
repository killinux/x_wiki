# .x 配件与舞台(アクセサリ / ステージ)

MMD 里除了 PMX 模型,还有 **DirectX `.x` 格式**的配件(アクセサリ)和舞台(ステージ)。道具、饰品、背景、地板常以 `.x` 提供。

## .x 配件构成
一套配件通常是:
- **`.x`** — 3D 数据本体(网格 + 材质 + 贴图引用)
- **`.vac`** — 位置/朝向/缩放等摆放信息(可选)
- **贴图** — `.bmp` / `.tga` 等
(来源: 3dcgr2lab 配件制作)

## 与 PMX 的区别
| | `.x` 配件 | `.pmx` 模型 |
|---|---|---|
| 骨骼 | **无**(整体刚性) | 有 |
| 加载位置 | 「アクセサリ操作」面板 | 「モデル操作」面板 |
| 跟随角色 | 靠**外部親/绑骨**(见 [[外部親-accessory]]) | 自身有骨 |
| 物理/表情 | 无 | 有 |

> 现在很多「舞台/背景」其实是 **PMX** 格式(可带骨/物理),从「モデル操作」加载;纯 `.x` 多为简单道具或老素材。(来源: モデログ ステージ)

## 制作(简述)
- 用 **Metasequoia**(或 Blender 导出)做网格 → 存为 `.x`。
- 要点:原点对齐 MMD、材质用**相对路径**且贴图同目录、导出时勾 UV 映射。
- Blender 可经 [[mmd_tools]] 直接做成 PMX 配件/舞台,通常比 `.x` 更灵活。

## 在 MMD 里用
- アクセサリ操作 → 読込 选 `.x`。
- 调位置/旋转/缩放;要跟角色手就设外部親到 `右手首` 或 ダミー 骨(见 [[外部親-accessory]])。
