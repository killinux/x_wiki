# 表情 / 变形 (モーフ / morphs)

MMD 的「表情」是 morph(形态键),由 VMD 中的表情轨道驱动。同样**按日文名匹配**。

## 变形类型
PMX 支持多种 morph:
- **顶点变形(頂点)**:最常见,移动顶点 → 做嘴型、眨眼、口型。
- **骨骼变形(ボーン)**:通过骨骼位移/旋转实现(如某些口型、辅助骨)。
- **材质变形(材質)**:改材质颜色/透明度/贴图系数 → 脸红、消失效果。
- **UV 变形**:平移 UV → 眼神光移动、流动贴图。
- **组变形(グループ)**:组合调用多个 morph,做复合表情。

## 分类面板(MMD 表情面板四类)
MMD 表情面板按类别分组:**眉 / 目 / 口 / その他(其他)**。建模时按此归类便于使用。

## 关键口型 / 眨眼(常见日文名)
| 日文 | 含义 |
|---|---|
| まばたき | 眨眼 |
| 笑い / ウィンク | 笑 / 眨单眼 |
| あ・い・う・え・お | 五个元音口型(对口型基础) |

> 元音口型 `あいうえお` 是对口型(lip sync)的核心,务必做齐。

## 在 Blender 中
- 用 **Shape Keys(形态键)** 制作顶点 morph。
- [[mmd_tools]] 把 Shape Keys 导出为 PMX 顶点 morph,并能在面板里指定分类(眉/目/口/その他)。
- 骨骼/材质/UV/组 morph 需在 mmd_tools 的 morph 工具里另行配置。

参见 [[pmx-format]]、[[骨骼-bones]]。

> 待补充:Blender Shape Key 命名与 MMD 日文表情名的映射约定——ingest 后补全。
