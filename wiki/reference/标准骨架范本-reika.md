# 标准骨架范本 — Reika(实测)

本页是对一具**绑定完整的成品 PMX**(`Reika18_Children.pmx`,PMX 2.0)的解析结果,作为「标准 + 准标准骨架应该长什么样」的**已验证范本**。所有数值由二进制解析得到,可直接当对照表用。

> 用途:学习/对照标准骨架结构、IK 链、付与系数。模型本身是第三方成品,**复用其部件受原作分发条款约束**(见 [[xps-转换常见问题]] 版权一节)。

> ⚠️ **全角/半角坑(实测踩到)**:本模型的拇指根骨是全角 `親指０`(不是半角 `親指0`),IK 骨用全角 `ＩＫ`。VMD 按日文名**精确匹配**,全角半角不可混 —— 这印证了 [[骨骼-bones]] 的警告。补骨/重命名时务必和目标动作用同一字符宽度。

## 付与(grant)系数(实测)—— 之前全靠推断,这里是真值

| 子骨 | 付与源 | 类型 | 系数 |
|---|---|---|---|
| 左/右肩C | 左/右肩P | 回転 | **-1.0**(抵消) |
| 腕捩1 / 腕捩2 / 腕捩3 | 腕捩 | 回転 | **0.25 / 0.5 / 0.75** |
| 手捩1 / 手捩2 / 手捩3 | 手捩 | 回転 | **0.25 / 0.5 / 0.75** |
| 足D / ひざD / 足首D | 足 / ひざ / 足首 | 回転 | **1.0**(完全跟随) |
| 左/右目 | 両目 | 回転 | 1.0 |
| 腰キャンセル左/右 | 腰 | 回転 | **-1.0** |

> **捩り分散**:腕捩/手捩 用 0.25/0.5/0.75 三段子骨把扭转沿手臂渐变分配,避免「糖纸」式塌陷。这是准标准骨「腕捩」真正起作用的方式。
> **D 系**:足D/ひざD/足首D 用系数 1.0 完全跟随可见足骨,专门承担蒙皮形变(控制/形变分离)。

## 关键父子层级(实测)

```
全ての親 → センター → グルーブ → 腰 ┬→ 下半身
                                  └→ 上半身 → 上半身2 → 首 → 頭 → 目
足链:  腰キャンセル左 → 左足 → 左ひざ → 左足首 → 左つま先
       (D系) 腰キャンセル左 → 左足D → 左ひざD → 左足首D → 左足先EX
IK:    全ての親 → 左足IK親 → 左足ＩＫ → 左つま先ＩＫ
腕链:  上半身(上部) → 左肩P → 左肩 → 左肩C → 左腕 → 左腕捩 → 左ひじ → 左手捩 → 左手首 → 各指/ダミー
```

> 注意:腿不是直接挂在「下半身」上,而是挂在 `腰キャンセル左/右`(由腰 -1.0 付与),这让腰旋转时大腿能保持朝向。这是高质量绑定的常见做法。

## 表情(19)实测分布

| 面板 | 数量 | 实测项 |
|---|---|---|
| 口 | 8 | あ / あ２ / い / う / え / お / にやり / 激怒 |
| 目 | 6 | まばたき / 笑い / ウィンク / ウィンク右 / びっくり / じと目 |
| 眉 | 5 | 困る / 怒り / 真面目 / 上 / 下 |

> ⚠️ **反常发现:这 19 个表情全部是「骨骼 morph(bone-type)」,没有一个顶点 morph。** 即面部用**表情骨**驱动(あ 动 8 根骨、笑い 动 30 根骨),而不是常见的顶点形变。
>
> 这条**修正**了 [[表情-morphs]] / [[xps-to-mmd-流程]] ⑥ 的默认假设(「表情=顶点 morph=Blender Shape Key」)—— 那是最常见情形,但**并非唯一**:也有模型(如本范本)用骨骼 morph 做脸。从 Blender 走 [[mmd_tools]] 时,Shape Key 导出的是顶点 morph;若要做骨骼 morph 风格,需在 PMXEditor 里另建。这是个值得记一笔的真实反例。

## 物理(刚体 48 / 关节 29)实测

- 刚体形状:カプセル(胶囊)40、箱 6、球 2。
- 刚体模式:静(骨追従)20、動(物理)28。
- 关节 29(把动刚体串成链:头发/裙/饰品等)。
> 头发/裙摆这类多用胶囊刚体 + 关节链(动刚体);静刚体贴在身体骨上做碰撞墙。动刚体(28)略多于静(20),符合「以飘动部件为主」的中等规模物理。可作为 [[物理-physics]] 的规模参考。

## 怎么把它当工具用

1. **对照重命名**:转 XPS/VRoid 模型时,拿本页骨名表当目标命名(注意全角)。见 [[xps-骨骼映射]]。
2. **抄付与系数**:补准标准骨时直接套用上面 0.25/0.5/0.75、-1.0、1.0 这些真值。
3. **抄层级**:腰キャンセル、肩P/肩C 的接法照搬即可。
4. **规模基准**:表情/刚体/关节数量给你一个「完整模型大概多少」的量级感。
