# 素材站与使用规约

MMD 生态的模型/动作/配件来源,以及**绕不开的使用规约**。转换/二次创作前必读规约——这关系到能否合法分享(呼应 [[xps-转换常见问题]] 的版权一节)。

## 主要素材站

| 站点 | 说明 |
|---|---|
| **BowlRoll**(bowlroll.net) | 日本主流 MMD 文件站,常**带密码**(密码在视频简介或 readme 里) |
| **ニコニ立体**(3d.nicovideo.jp) | Niconico 的 3D 平台,浏览器内可预览 PMX |
| **DeviantArt** | 西方 MMD 社区,模型/动作量大 |
| **BOOTH / X(Twitter)** | 收费与免费分发都有 |

> XPS/XNALara 素材多来自游戏 rip,分发限制更严(见 [[xps-format]]、[[xps-转换常见问题]])。

## 使用规约(規約 / readme)—— 必读

每个模型/动作都附 **readme(説明書 / 利用規約)**,常见条款:

- **再配布(redistribution)禁止**:不可转载/二次上传原文件。
- **改変(modification)**:是否允许改模、改后能否分发,**因作者而异**。
- **クレジット(credit)**:使用时需署名作者。
- **禁止用途**:R-18、商用、政治/宗教、损害角色形象等。
- **格式转换/移植**:把模型转成别的格式再分享,**通常需原作者许可**。

> 实务原则(同 [[xps-转换常见问题]]):**转换后的模型默认仅个人使用,不公开分发**,除非原作 readme 明确允许且你遵守其条款。
