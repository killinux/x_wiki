# 问题排查 (Troubleshooting)

按「症状 → 可能原因 → 解法」记录。每个独立问题可单开一页 `症状关键词.md`。

## 待建条目(占位)
- **动作对不上 / 模型不动** → 骨骼名不匹配。见 [[骨骼-bones]]。
- **贴图丢失 / 路径乱码** → 导出后路径/编码问题。见 [[材质-materials]]。
- **裙摆 / 头发穿模** → 非碰撞组、碰撞器缺失。见 [[物理-physics]]。
- **物理抖动 / 爆炸** → 质量差、关节限制、刚体重叠。见 [[物理-physics]]。
- **关节处变形塌陷** → 权重 / SDEF。见 [[权重-weights]]。
- **导出丢数据** → MMD Model 根层级被破坏。见 [[mmd_tools]]。

> 遇到具体报错时,把现象 `ingest` 进来,我会建成完整的排查页并交叉引用。
