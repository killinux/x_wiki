# 问题排查 (Troubleshooting) 索引

按「症状 → 去哪页找解法」组织。详细条目见各专页。

## 症状速查

| 症状 | 多半原因 | 去哪页 |
|---|---|---|
| 动作加载后模型**散架/扭曲** | 骨名不匹配、坐标/roll、绑定姿势 | [[xps-骨骼映射]]、[[坐标系-朝向-pose]] |
| 模型**不动**(动作没反应) | 骨名非日文标准名/全角半角不符 | [[xps-骨骼映射]]、[[标准骨架范本-reika]] |
| 手臂**拧成糖纸** | 骨骼 roll 不一致、缺扭转骨 | [[坐标系-朝向-pose]]、[[准标准骨骼-semi-standard-bones]] |
| 表情**滑块调不出** | morph 没进「表情」显示枠 | [[blender-mmd-绑定改造]] |
| 脚**滑/IK 不工作** | IK 骨缺失/链长错 | [[blender-mmd-绑定改造]]、[[骨骼-bones]] |
| 导入后模型**极大/极小/不可见** | 单位/缩放,未 Apply Scale | [[xps-转换常见问题]]、[[坐标系-朝向-pose]] |
| 贴图**全白/全黑/丢失** | 路径/特殊字符/Diffuse 黑 | [[xps-转换常见问题]]、[[材质-materials]] |
| 透明件**穿透/闪烁** | 绘制顺序 | [[材质-materials]]、[[pmxeditor]] |
| 裙/发**穿模** | 非碰撞组、缺碰撞器 | [[物理-physics]] |
| 物理**抖动/爆炸** | 质量差、关节限制、刚体重叠 | [[物理-physics]] |
| 关节处**塌陷** | 权重 / 缺 SDEF | [[权重-weights]] |
| 导出**报错/丢数据** | MMD Model 根层级被破坏、无 armature modifier | [[xps-转换常见问题]]、[[mmd_tools]] |
| 面数过高**卡顿** | 游戏模型面数高 | [[xps-转换常见问题]](Decimate) |
