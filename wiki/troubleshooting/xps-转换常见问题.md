# XPS → MMD 转换常见问题

## 导入阶段

### 导入后模型不可见 / 极小 / 极大
- **原因**:XPS 模型的单位与 Blender 不同,缩放可能差几个数量级。
- **解法**:在 Outliner 中确认模型存在 → 选中 → `S` 缩放至合适大小 → `Ctrl+A` Apply Scale。
- **参考大小**:MMD 标准角色约 20 Blender 单位高。

### 贴图全白 / 全粉 / 丢失
- **原因**:贴图文件不在模型同目录下,或文件名含特殊字符(中文/日文/空格)。
- **解法**:
  1. 确保贴图文件和模型文件在同一文件夹
  2. 在 Shader Editor 中手动指定正确的贴图路径
  3. 必要时重命名贴图文件去掉特殊字符

### 插件报错 / Import 菜单中无 XPS 选项
- **原因**:XPS Tools 版本与 Blender 版本不兼容。
- **解法**:确认使用的 fork 支持当前 Blender 版本。Blender 4.x 需要专门适配的版本。

## 骨骼阶段

### Cats Fix Model 后骨骼位置不对
- **症状**:骨骼飞到奇怪的位置,或者肢体扭曲。
- **原因**:Cats 自动处理时错误合并/重定向了骨骼。
- **解法**:Undo,改用手动重命名。或在 Cats Fix 前先手动修正最关键的几个骨骼名。

### 动作加载后角色变形/散架
- **原因**:骨骼名没有正确映射为 MMD 标准名,VMD 找不到对应骨骼。
- **解法**:检查 [[xps-骨骼映射]] 对照表,确保所有关键骨骼名称正确。

### IK 不工作 / 脚滑
- **原因**:IK 骨骼未正确创建,或 IK 链长度不对。
- **解法**:
  1. 确认 左足ＩＫ / 右足ＩＫ 存在且位于脚底
  2. 检查 IK 链长度(通常为 2)
  3. 确认 IK 骨骼的 parent 设置正确

## 权重阶段

### 某个部位不跟随骨骼运动
- **原因**:该区域的顶点没有分配到对应骨骼的顶点组。
- **解法**:Weight Paint 模式 → 选对应骨骼 → 刷权重。

### 合并 mesh 后权重丢失
- **原因**:合并时顶点组名称冲突或未正确传递。
- **解法**:合并前确保各 mesh 的顶点组名称一致(指向同一骨骼的用同一名称)。

### 对称动作不对称
- **原因**:左右权重不对称。
- **解法**:选择一侧 → Mirror Weights(需要骨骼名包含 L/R 或 左/右 标记)。

## 材质阶段

### 导出 PMX 后贴图全黑
- **原因**:mmd_tools 的材质设置中 Diffuse 颜色为黑色,会与贴图相乘。
- **解法**:将 Diffuse 颜色设为白色 (1, 1, 1)。

### 透明材质渲染顺序错误(穿透/闪烁）
- **原因**:PMX 中透明材质的绘制顺序不对。
- **解法**:在 PMXEditor 中调整材质顺序,不透明的放前面,透明的放后面。

## 导出阶段

### 导出时报错 "Object has no armature modifier"
- **原因**:mesh 没有正确绑定到 armature。
- **解法**:选中 mesh → 再选 armature → `Ctrl+P` → Armature Deform(不要 With Automatic Weights,保留已有权重)。

### 导出的 PMX 在 MMD 中模型全白
- **原因**:贴图未复制到 PMX 同目录,或贴图路径为绝对路径。
- **解法**:导出时勾选 Copy Textures;或手动将贴图复制到 PMX 文件所在文件夹,在 PMXEditor 中修正路径为相对路径。

### 模型在 MMD 中显示正常但动作不动
- **原因**:骨骼名称与 VMD 不匹配。
- **解法**:回到 [[xps-骨骼映射]],确认骨骼使用日文标准名。VMD 按名称匹配骨骼。

## 其他

### 模型面数过高导致 MMD 卡顿
- **原因**:游戏模型面数本身就高,XPS rip 可能有大量不必要的细节。
- **解法**:在 Blender 中使用 Decimate Modifier 降面。建议 MMD 用模型控制在 5 万面以下(根据硬件而定)。

### 版权问题
- XPS 社区对模型的再分发(redistribution)通常有限制。转换后的 PMX 模型是否可以分享,取决于原始 XPS 模型的使用条款。
- 建议:仅个人使用,不公开分发转换后的模型,除非原作者明确允许。
