# 导出前 QA 清单(XPS→MMD)

从 Blender 导出 PMX **之前**逐项过一遍,能挡掉绝大多数「导出后才发现」的返工。出问题时配合 [[xps-转换常见问题]] 查解法。

## 几何 / 变换
- [ ] 模型站立、朝向正确,**旋转 + 缩放已 Apply 归零**(Armature 和 Mesh 都做)。见 [[坐标系-朝向-pose]]
- [ ] 法线朝外(Face Orientation 全蓝),无翻面
- [ ] 已 Merge by Distance 去重叠顶点,无松散点/边
- [ ] 面数在目标范围(MMD 用建议 ≤ 5 万面,视硬件)

## 骨骼
- [ ] 标准骨齐全、用 **MMD 日文名**(注意全角/半角,如 `親指０`、`ＩＫ`),见 [[xps-骨骼映射]] / [[标准骨架范本-reika]]
- [ ] 准标准骨按需补齐(腕捩/手捩/グルーブ/足D…),见 [[准标准骨骼-semi-standard-bones]]
- [ ] IK 链正确(足ＩＫ 链长 2、つま先ＩＫ 链长 1),膝有微弯朝向
- [ ] 付与设好(肩C −1.0、腕捩 0.25/0.5/0.75、足D 1.0)
- [ ] 手臂链 **roll 统一**(防扭转麻花)
- [ ] 左右对称、L/R 命名正确
- 细节见 [[blender-mmd-绑定改造]]

## 权重
- [ ] Vertex Group 名与骨名一致(改名后已同步)
- [ ] 每顶点 **≤ 4 骨**(Weight Tools → Limit Total = 4)
- [ ] 控制骨(IK / 肩P / 足IK親 / センター / グルーブ)**顶点组为空**
- [ ] 关节处(肘/膝/腕)变形平滑,旋转测试无塌陷/撕裂
- 见 [[权重-weights]]

## 材质
- [ ] Diffuse 颜色为白 (1,1,1),贴图正确加载(防全黑)
- [ ] 透明材质标志 + 绘制顺序(防穿透/闪烁)
- [ ] 双面需求已勾「両面描画」
- [ ] Toon / 描边按需设置;丢弃 MMD 不支持的法线/specular
- 见 [[xps-材质差异]] / [[材质-materials]]

## 表情(可选但建议)
- [ ] 至少 `まばたき` + `あいうえお`,Shape Key 用日文名
- [ ] morph 已归类到 眉/目/口/その他 面板
- 见 [[表情-morphs]]

## 物理(可选)
- [ ] 身体碰撞器(静刚体)+ 飘动链(动刚体 + 关节)
- [ ] 非碰撞分组设好(防穿模)
- [ ] 参数参考范本值(动刚体衰减 ~0.95、回弹 0),见 [[物理-physics]]

## 导出 / 显示枠
- [ ] 显示枠分组排好(不进枠的骨在 MMD 点不到),见 [[blender-mmd-绑定改造]]
- [ ] 导出勾 **Copy Textures**,贴图随 PMX 同目录,路径为相对路径
- [ ] 导出后进 [[pmxeditor]]:TransformView 摆 pose、加载一个标准 VMD 实测动作
