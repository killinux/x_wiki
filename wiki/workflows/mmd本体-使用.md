# MMD 本体使用(MikuMikuDance.exe)

做完模型后,最终在 **MikuMikuDance 本体**(Windows 免费软件)里加载、配动作、跑物理、出片。这页是「模型做好之后怎么用」的最小流程,也是验证 [[blender-to-pmx-导出流程]] 成果的终点。

## 1. 加载模型
- 左下「モデル操作」区 → **読込(Load)** → 选 `.pmx`/`.pmd`。
- 模型出现,骨骼进入帧操作区。模型放 `UserFile/Model` 下便于管理。

## 2. 加载动作(VMD)
- 选中模型 → ファイル → **モーションデータ読込** → 选 `.vmd`。
- 动作按**骨骼名**套用(见 [[vmd-动作格式]]);名字对不上的轨道会被忽略 → 回查 [[xps-骨骼映射]]。
- 按播放预览。

## 3. 物理演算
- 物理菜单三种模式:**on/常时**、**on/トレース**、**off**。
- 头发/裙/胸的甩动需要开物理(见 [[物理-physics]])。
- 物理炸开/抖动 → 回查刚体/关节(见 [[物理-physics]] 调参)。

## 4. 相机 / 表情
- 模型下拉切到 **カメラ** 可单独加载相机 VMD。
- 表情滑块读模型「表情」显示枠里的 morph —— **枠空 = 调不出表情**(见 [[blender-mmd-绑定改造]] ④ 与 [[标准骨架范本-reika]] 反例)。

## 5. 外部親 / 配件
- 让模型拿武器、戴眼镜、踩平台 → 见 [[外部親-accessory]]。

## 6. 出片
- ファイル → **AVI出力**:选编码器、帧范围。
- 或 **画像出力**:输出 PNG/BMP 序列,便于后期合成(背景可设白/透明)。
- 加特效(辉光/景深/PBR)→ 见 [[mme-特效]]。

## 注意
- 共享 toon(toon01–10)放在 MMD 的 `Data` 目录,模型才正确显示(见 [[toon-贴图对照]])。
- MMD 本体只完整支持 **PMX 2.0**(见 [[pmx-format]])。
