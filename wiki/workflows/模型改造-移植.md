# 模型改造 / 部件移植

把现成 MMD 模型改体型、换衣服/头发、移植部件,是常见二创需求。主要在 [[pmxeditor|PMXEditor]] 或 Blender([[mmd_tools]])里做。

> ⚠️ **改造前先看规约**:模型 readme 必须允许改造(改変);见 [[素材站与规约-resources]]。多数日本模型对改造/再分发有严格限制。

## 体型改变(サイズ変更)
- PMXEditor:**編集 → プラグイン → System → サイズ変更**,数值 <1.0 缩小、>1.0 放大(可整体或选定部分)。(来源: leveler diarynote)
- 改完检查权重、物理刚体位置是否跟着变。

## 部件移植(衣服/头发等)
典型流程(来源: 紳士MMDer wiki 衣装移植;gentle wiki):
1. **基底模型**:在 PMXEditor 打开目标模型,删掉要替换的旧部件(对应网格 + 其刚体 + Joint + 专属骨)。
2. **取出源部件**:打开源模型,用**「頂点/材質マスキング」**只留要移植的材质(如只留头发),删掉其余网格/骨/刚体。
3. **缩放对齐**:把源部件缩放/位移到基底模型的比例与位置。
4. **接骨/刷权重**:把部件绑到基底的对应骨(头发→頭、衣服→躯干骨),刷权重(见 [[权重-weights]])。
5. **补物理**:头发/裙重新加刚体+关节(见 [[物理-physics]])。

## 常见坑
- 移植后**权重指向的骨名对不上** → 部件不跟随;统一骨名(见 [[骨骼-bones]])。
- **材质重名/贴图丢失** → 检查材质槽与贴图路径(见 [[uv-贴图打包]])。
- 体型改后**物理穿模/抖动** → 刚体位置/大小要跟着改(见 [[物理-physics]])。
- 同样别忘**全角/半角**骨名一致,否则动作驱动失败(见 [[标准骨架范本-reika]])。

## Blender 路线
- 也可在 Blender 里用 [[mmd_tools]] 导入双方 PMX、合并网格、转移权重(类似 [[xps-to-mmd-流程]] 的手法),再导出。
