# sources/ — 原始资料

把你收集的原始资料放这里,Claude **只读不改**。然后在本目录对 Claude 说 `ingest sources/<文件>`。

适合放的东西:
- 教程 / 视频的文字笔记(`.md` / `.txt`)
- 官方文档、插件 README 的摘录
- 论坛 / Discord / 贴吧的问答记录
- 自己的踩坑记录、参数截图说明

建议命名:`YYYY-MM-DD_来源_主题.md`,例如 `2026-05-29_mmd_tools官方_物理设置.md`,方便 `log.md` 追溯。

> 也可以不落盘,直接把内容粘贴给 Claude 说「ingest 这个」。
